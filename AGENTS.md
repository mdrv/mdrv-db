# AGENTS.md

**Naming (strict):** everything user-facing in this project must carry the full
`mdrv-db` form — `mdrv-db` / `MDRV_DB_*` / `MdrvDb` / `mdrv_db` — never the bare
`mdrv` / `Mdrv` / `MDRV`, which is the author's personal handle and collides
with their other unrelated projects. The `@mdrv` npm scope and `mdrv_db`-style
crate names are the allowed namespaced forms.

**Privacy:** keep repository content generic — no personal data, hostnames, or
paths in code, docs, or history.
